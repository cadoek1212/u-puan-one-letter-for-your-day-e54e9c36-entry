One letter for the day:

> **Z — "zero sleep"**

A night with literally zero sleep: the hyperbolic "zero" lands at once, everyone has lived it, and Z is the sharp initial of "zero". The program scores 12 original letter-and-word candidates against the judge's criteria (vivid, funny, true, letter-fit) in a full pairwise round-robin tournament and writes the champion to `/output/entry.txt`. Fully deterministic — two runs produce byte-identical output.

## Run it

```sh
python3 main.py
```
